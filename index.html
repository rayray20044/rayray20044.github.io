01 — Selected work

Featured project

One project that uses everything: hardware, a server and API, a live dashboard and data processing.

Embedded systems · IoT · Healthcare research · 2026

Waves: A Sensor Headset for Parkinson's Speech Research

A wearable headset that records how Parkinson's patients speak and move, for a research group studying the link between language and movement. It started as an SRH Berlin project with SRH Hochschule für Gesundheit, and we developed it further at the 2026 Sino-German Design Innovation Workshop in China, where our team earned a Certificate of Achievement.

★ Certificate of Achievement3rd Sino-German Design Workshop · Sep 2026

What it does

  • Captures speech, mouth movement and body motion at the same time
  • Streams live data to a web dashboard where researchers start and stop sessions
  • Measures sound level, mouth opening and movement for each recording

How we built it

  • Raspberry Pi with an MPU-6050 motion sensor (I²C, 40 Hz), an INMP441 mic and a camera
  • Python streamer on the Pi sending motion, audio and live video over WebSockets
  • TypeScript server with SQLite storage, a documented REST API and face-mesh mouth tracking
  • React dashboard for live charts, video and reviewing recorded sessions
  • Raspberry Pi
  • Python
  • I²C sensors
  • WebSockets
  • TypeScript
